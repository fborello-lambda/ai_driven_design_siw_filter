## 1. Project

A parametric SIW bandpass filter, **f0 = 2.87 GHz**, 5 % FBW (143.5 MHz),
0.1 dB Chebyshev, S11 ≤ −16 dB in band. Python package `src/siwfilter/`
(console script `siw`), Palace FEM for EM, outputs a KiCad/JLCPCB fab package
and a parametric CST 2021 `.bas` macro.

**Fabricated design (2026-09-23): cascade N=3, end cavities trimmed −0.3 mm**
— `l_cav1=33.939, l_cav2=35.503, w_iris=14.416, w_ext=13.96, l_taper=15.738,
w_ms=1.6636`, CPWG launch. Fine-mesh: fc 2.876 GHz, BW 182 MHz, S11w
−11.15 dB. Misses spec; the deviation is accepted and documented. Package:
`docs/final_check/fab/`; provenance: `golden/cascade_N3/`.

Dual-mode N=2 (single cavity) was the earlier candidate; it lost the
head-to-head (`siw compare-designs`) and is a documented negative result.

### Fixed configuration — single source of truth is `config.py`
- Substrate `RO4350B_0.76mm` (εr 3.66, tanδ 0.0037, h 0.76 mm, 0.5 oz Cu).
  Other presets in `SUBSTRATES`; dielectric loss `kappa = 2π f0 ε0 εr tanδ`.
- Vias **d = 1.5 mm, p = 3.0 mm** (`VIA_PRESETS["siw_fence"]`). Smaller sizes
  were searched three times under three scoring methods and never matched —
  do not shrink them for fab reasons alone.
- Connector: Taoglas EMPCB.SMAFSTJ.B.HT. 0.5 oz copper matters for the SMA
  fork fit (JLCPCB offers only 1 oz — see REPORT.md §4).

## 2. Environment

- `uv sync` installs everything. Palace is found via `$PALACE_BIN`, `palace`
  on `$PATH`, or `~/opt/palace/bin/palace` (`config.find_palace()`).
- openEMS is no longer used by the package (earlier phases only).

## 3. Working rules

- **Use the CLI, not one-off scripts.** `siw measure`, `siw calibrate`, `siw synth-design`,
  `siw design --seed/--span/--patience`, `siw kicad`, `siw cst`, `siw
  compare-*`. Every bug found in the 2026-08-30 session was in throwaway
  orchestration scripts (loop variable collapsing N=3/N=4 onto one tag,
  KeyError in a cavity-length map, carrying an unmeasured extrapolation
  forward); the library code held up.
- Keep all tunable numbers in `config.py`; modules import from it.
- `golden/<topology>_N<order>/` holds curated designs + measured S-params.
  Get the launch tag right (`cpwg_taoglas` vs pad-only `sma_taoglas`, see
  `golden/README.md`) — a launch-model mismatch has already bitten once.
- Generated artifacts go to `output/` (gitignored except the calibration
  cache). Committed figures live in `docs/`.

## 4. CST `.bas` requirements

Native 3D solids in CST 2021, generated by `cst_export.py`:
- `StoreParameter` for every dimension (`rvia`, `p_via`, `L_cav*`, iris
  widths, taper dims, `eps_r`, `tan_d`, `h_sub`, …).
- **Wrap every geometry block in `AddToHistory(header, body)`**, or solids
  vanish on the next History rebuild.
- Substrate `Brick` (Normal material, `.Epsilon`/`.TanD`), PEC grounds, via
  `Cylinder`s (`.Axis "z"`, `.Segments "0"`); an iris is a gap in a via row.
- Real Taoglas SMA coax stubs + coaxial ports; solver setup included (TD by
  default, FD variant unverified in CST).

## 5. Design method: calibrate and invert (not black-box search)

- `CascadeTopology.calibrate()` — k(w_iris) from a 2-cavity closed eigenmode,
  `k = (f2² − f1²)/(f2² + f1²)`; fit w(k).
- `calibrate_qe()` — Qe(w_ext) from one doubly-loaded driven cavity,
  `Qe = 2/(1/Q_L − 1/Qu)`, Q_L from the −3 dB width. Caveat: Qu is taken as
  the dielectric limit 1/tanδ (270), so Qe is slightly over-estimated.
- `synth_design.py` inverts both, assembles, fine-confirms. Use the GP only as
  a **local** polish (`--seed`).

**Why:** a global GP over the assembled cascade never beat −5 dB S11 in 60+
evals. Passband width is **discontinuous** in w_ext (16/22/36/65/215 MHz on
N=3, target inside the jump); GPs model smooth functions. The calibrations
measure smooth observables on small structures and converge in ~3 solves.

Never trust a closed-form SIW iris-width formula — #1 source of first-design
failure.

## 6. Physics reference

- Cassivi–Wu: `a_eff = a_siw − d²/(0.95 p)` (refined: `a_siw − 1.08 d²/p + 0.1 d²/a_siw`).
- TE10 cutoff `fc = c / (2 a_eff √εr)`; operate near 1.4 fc; single-mode to 2 fc.
- TE101: `f101 = c/(2√εr) · √((1/a_eff)² + (1/L_eff)²)`.
- Via rules: 0.5 ≤ p/d ≤ 2.5; d < λg/5; d < a_eff/5; p < λ0√εr/4.
- Chebyshev g-values (Hong–Lancaster Ch. 3); `k[i,i+1] = FBW/√(g_i g_{i+1})`,
  `Qe = g0 g1 / FBW`. N=3, 0.1 dB, 5 %: g1=g3=1.0316, g2=1.1474 → k ≈ 0.046,
  Qe ≈ 20.6. N=2: k12 ≈ 0.069, Qe ≈ 16.9.
- Qe by group delay: `Qe = ω0 τ_S11(ω0) / 4`.
- SIW impedance `Z = π² η h / (8 a_eff √(1 − (fc/f)²))`; taper ≈ λg/4.
- Measured sensitivity on this board: end-cavity length ≈ 27 MHz/mm (not the
  ~50 MHz/mm rule of thumb).

References: Deslandes & Wu TMTT 2003/2006; Cassivi et al. MWCL 2002; Xu & Wu
TMTT 2005; Deslandes IMS 2010; Bozzi/Georgiadis/Wu IET MAP 2011; Hong &
Lancaster *Microstrip Filters* Ch. 3 & 8; Cameron TMTT 2003; Chen & Wu TMTT 2008.

## 7. Known pitfalls and closed questions (paper material)

**Bugs that invalidated earlier results** — don't trust numbers predating the fix:

| bug | effect | fix |
|---|---|---|
| `w_iris` quantized (arms filtered from a fixed grid) | cascade search box spanned ~2 geometries | `ea44a21` |
| N≥4 had one shared iris width | asymmetric k profile unreachable | `fc0dcbd` |
| `FilterSpec` vias stale 0.8/1.5 mm | cascade simulated the wrong fence | `a58dbc9` |
| `CascadeTopology.calibrate()` was a stub | no calibrated design region | `a5877cd` |
| eigenmode pair = smallest gap | picked a higher-order cluster, k 21× low | `a5877cd` |
| dualmode `build_mesh()` dropped `soldermask`/`via_conductivity` | fab studies ran with the feature no-op'd | `13af8cc` |
| coarse-mesh golden S11 (−13.37 dB) | fine mesh gives −10.7 dB; coarse was an artefact | 2026-09-23 |

**Palace conductivity BC:** `Boundaries.Conductivity` is only valid on true
one-sided exterior faces. Vias and the trace here are internal two-sided PEC
sheets, so lossy-conductor studies (filled vs unfilled vias, ENIG vs OSP)
need real excluded 3D conductor geometry. **Don't patch it with boundary
tags** — that silently gives invalid results (e.g. −7.8 dB IL on solid copper).

**N=4 compact is closed.** Five mechanisms plus a joint GP on dual-mode
cascades / quad-mode cavities all hit the same 2-of-4-pole ceiling; read
`docs/geometry_exploration/dualmode_cascade_v6_handoff_2026-08-28.md` §9–16
(tag `docs-archive-2026-09-29`)
before trying any variant (offset apertures, corner placement, posts,
top-copper slots, quad-mode are already falsified). A 4-cavity single-mode
cascade works but needs ~180–206 mm.
