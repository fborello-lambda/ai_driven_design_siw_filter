Waveguide (SIW) bandpass filter**. The human did the environment bootstrap (openEMS C++

## 1. Goal / final deliverable

- A **parametric SIW bandpass filter** designed in Python.
- Center frequency **f0 = 2.87 GHz** (S-band).
- Topology: **inline inductive-iris coupled SIW cavities** (each cavity resonates in TE101),
  Chebyshev response, configurable order N and ripple.
- **The final outcome the human expects is a native 3D solid model in CST Studio Suite
  2021** (real `Brick`/`Cylinder` solids in the modeler, parametric, simulation-ready),
  generated by a Python-written `.bas` VBA macro. CST is the FINAL authority; openEMS is a
  fast pre-check.

### Must be VARIABLE parameters (the human asked for these explicitly)
- **Via diameter** `d_via` (default 0.8 mm).
- **Substrate** — both material AND thickness. Stock confirmed from datasheets
  (see `SUBSTRATES` in `config.py`, which is the single source of truth):
  - RO4350B: eps_r = 3.66, tan_d = 0.0037 — h = 1.52 / 0.76 / 0.25 mm
  - RO4350B 4-mil laminate: eps_r = 3.36 (spec Dk differs), tan_d = 0.0037, h = 0.10 mm
  - AD250C: eps_r = 2.50, tan_d = 0.0013, h = 1.524 mm  ← **default**
  - Dielectric loss for openEMS/CST: `kappa = 2*pi*f0*eps0*eps_r*tan_d`.
- **Via pitch** `p_via` (default 1.5 mm; keep p/d between 0.5 and 2.5, target ~2).
- **Number of cavities** N (filter order), **cavity length** per cavity,
  **iris widths** (there are N+1 coupling structures for N cavities), **number of irises**.

  via row centered on the SIW axis.
- Microstrip-to-SIW tapers: `Polygon3D` + `ExtrudeCurve` (or a swept trace), copper.
- Two ports on the SIW/feed end faces (waveguide-style or microstrip).

## 6. The one numerically critical step: iris-width <-> k calibration

DO NOT trust any closed-form iris-width formula for SIW — it is the #1 source of first-design
failure. Build a calibration:
- In `calibrate.py`, simulate **two coupled SIW cavities** in openEMS, sweep iris width w,
  extract the eigenmode pair (f1, f2), compute `k = (f2^2 - f1^2)/(f2^2 + f1^2)`, fit a
  polynomial `w(k)`. Cache results to JSON keyed by (substrate, d_via, p_via) so it's reused.
- External Q: single resonator fed by the taper; extract via group delay
  `Qe = omega0 * tau_S11(omega0) / 4`. Fit `Qe(taper_param)`.
- `siw_geometry.py` then reads these fits to pick physical iris widths / taper from the
  synthesized k and Qe.
A fast first pass can use analytical estimates to get the layout drawing going, but the
openEMS/CST numbers must come from calibration.

## 7. Design-equation cookbook (reference)

Constants: c = 2.998e8 m/s.

- SIW equivalent width (Cassivi-Wu):  `a_eff = a_siw - d_via^2 / (0.95 * p_via)`
  (refinement if needed: `a_eff = a_siw - 1.08*d^2/p + 0.1*d^2/a_siw`).
- TE10 cutoff:  `f_c10 = c / (2 * a_eff * sqrt(eps_r))`. Operate near 1.4*f_c
  (i.e. choose f_c ~ 0.7*f0). Single-mode up to 2*f_c10.
- TE101 cavity resonance:
  `f101 = (c / (2*sqrt(eps_r))) * sqrt( (1/a_eff)^2 + (1/L_eff)^2 )`
  with L_eff = L_cav corrected for via row + iris loading.
- Via rules: 0.5 <= p/d <= 2.5 (use ~2); d < lambda_g/5; d < a_eff/5; p < lambda0*sqrt(eps_r)/4.
- Chebyshev: implement g-value recursion (Hong-Lancaster Ch.3). Example N=3, 0.1dB:
  g1=1.0316, g2=1.1474, g3=1.0316, g4=1.0.
- Bandpass mapping (FBW = (f2-f1)/f0):
  `k[i,i+1] = FBW / sqrt(g_i * g_{i+1})`,  `Qe = g0*g1 / FBW`.
- k extraction from EM:  `k = (f2^2 - f1^2)/(f2^2 + f1^2)`.
- Qe extraction:  `Qe = omega0 * tau_S11(omega0) / 4` (group-delay method).
- Microstrip-to-SIW taper: SIW char. impedance
  `Z_PI = (pi^2 * eta * h) / (8 * a_eff * sqrt(1 - (f_c/f)^2))`, match to 50-ohm microstrip
  via Hammerstad inverse; taper length L_t ~ lambda_g/4 in the microstrip at f0.

### Expected starting numbers
- Frequency-independent (depend only on N, ripple, FBW — VALID for the current
  default): for FBW = 5%, N=3, 0.1 dB -> g1=g3=1.0316, g2=1.1474, g4=1.0;
  k12 = k23 ~ 0.046, Qe ~ 20.6.  (verified by `synthesis.py`.)
- Geometry numbers below were computed for the ORIGINAL default
  (2.8 GHz, RO4003C eps_r=3.55, h=0.508mm); they will CHANGE for the new
  default (2.87 GHz, AD250C eps_r=2.50, h=1.524mm) — lower eps_r => larger
  a_eff/cavity, thicker h => wider 50-ohm microstrip. Recompute in
  `siw_geometry.py`, don't trust these verbatim:
  - Pick f_c ~ 0.7*f0 -> a_eff order ~40 mm, near-square cavity.
  - p_via ~ 1.5 mm (p/d ~ 1.875).
  - Estimated mid-band insertion loss a few dB (dielectric-dominated; AD250C
    tan_d=0.0013 is lower-loss than the old RO4003C example).
