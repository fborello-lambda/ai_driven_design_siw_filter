## 0. Why the method changed

Five bugs were found on 2026-08-30, each of which **independently** invalidated
every earlier cascade (N=3/N=4) search. **All pre-2026-08-30 cascade numbers are
void.**

| bug | effect | commit |
|---|---|---|
| `w_iris` QUANTIZED (arms filtered from a fixed via grid) | the whole search box spanned ~2 distinct geometries; the GP tuned a knob that did nothing | `ea44a21` |
| N≥4 had ONE shared iris width | could not express k = [0.0415, 0.0329, 0.0415]; N=4 spec unreachable by construction | `fc0dcbd` |
| `FilterSpec` vias stale at 0.8/1.5 mm | cascade simulated the wrong via fence (dual-mode unaffected — it uses its own constants) | `a58dbc9` |
| `CascadeTopology.calibrate()` = `return None` | no calibrated design region, so the box stayed centred on the documented mismatch-blind point | `a5877cd` |
| eigenmode pair = smallest gap | picked a higher-order mode cluster: k = 0.0028 instead of 0.0583 (21× error) | `a5877cd` |

**The pattern that decided the new method:** every step that measured a *smooth
observable on a small structure* converged (k within 2 % in ~3 solves; fc exact
for N=4). Every step that measured a *composite observable on the assembled
filter* failed — because the passband width is **discontinuous** in the external
coupling (below a threshold only the centre pole clears −3 dB so the band
measures one pole; above it all N poles merge: 16/22/36/65/215 MHz measured on
N=3, with the 143.5 MHz target inside the jump). A GP inherits that, since its
objective contains bandwidth and GPs model smooth functions.

**Method now:** calibrate → invert → assemble (`siw synth-design`), with the GP
demoted to a local polish around the result (`siw design --seed`).

## 2. Finish the filters

- [ ] `siw synth-design --N 3` and `--N 4` — invert both calibrations, fine-confirm.
  **This is the moment of truth**: proper equiripple passband, or not.
- [ ] If close but short of spec: `siw design --seed <design> --span 2 --patience 14`.
- [ ] Acceptance: symmetric response, S11 ≈ −16 dB worst-in-band, IL ≈ dielectric
  floor + ~1 dB, bandwidth → 143.5 MHz.
- [ ] **Verify against worst-in-band S11 and real bandwidth**, never the screen's
  best-in-window value. Two false-positive readings were made this session by
  conflating them.

## 3. Compare everything

## 4. Fabrication studies (new — for the dual-mode board)

Both are real manufacturing questions and both are cheap to simulate as A/B
pairs on an already-validated design.

- [ ] **Soldermask / silkscreen over the metal.**
  Expected to matter **at the feed, not the cavity**: the SIW cavity's fields are
  bounded between the two ground planes *inside* the substrate, so a coating on
  the outer copper barely perturbs them. The microstrip feed and Deslandes taper
  are different — their fringing fields are partly in air, so adding mask
  (εr ≈ 3.5–4, ~15–25 µm) raises the effective permittivity, lowering Z0 and
  changing electrical length. That detunes the launch and shifts the match.
  Simulate: bare copper vs mask-covered feed, compare S11 and fc.
  Silkscreen is a thin ink patch — likely negligible, but worth one A/B since it
  sometimes lands on the launch area.

- [ ] **Filled vs unfilled vias.**
  Prior expectation, to be tested not assumed: **minimal RF difference.** Copper
  skin depth at 2.87 GHz is **1.23 µm**, and typical barrel plating is 20–25 µm
  = 16–20 skin depths, so a plated barrel is already electrically equivalent to a
  solid post — current never reaches the fill. The plausible second-order effects
  are plating-thickness variation, voids, and (for via-in-pad) whether the fill is
  conductive or epoxy. Simulate: solid post vs hollow barrel with realistic
  plating, on the dual-mode design; report the delta honestly even if it is ~0.
  This is a good paper result either way — a null result with a stated mechanism.

## 6. Paper — "AI-Driven Design for SIW Filters"

Material already in hand, all with real numbers:

- **The core finding.** Black-box optimization over an assembled filter fails on a
  *structural* obstacle, not a tuning one: the objective is discontinuous. EM
  calibration of smooth observables on small structures, then inversion, converges
  in ~3 solves where 60+ driven evaluations did not.
- **The bug taxonomy (§0).** Five defects that silently made a search
  unwinnable — quantized parameters, missing degrees of freedom, stale
  configuration, unimplemented calibration, wrong mode selection. Directly useful
  to anyone automating EM design; most would pass unnoticed as "the optimizer
  didn't converge".
- **Diagnostics that worked**: screen-out rate as a search-health metric
  (dual-mode 34–37 % → 19 informative points and converges; cascade 57–83 % → 2–9
  and cannot); pole-count and ripple in S11 as a k-vs-Qe mismatch signature;
  coarse-vs-fine mesh disagreement as a false-positive source.
- **Honest negative results**: the N=4 compact dual-mode cascade (five mechanisms
  + joint GP, all at the same ceiling) and the offset-iris knob (looked good
  coarse, failed fine confirm).
- **Fabrication studies** (§4) and, if built, measured-vs-simulated.

Open question for the paper's framing: how much is genuinely "AI-driven" versus
classical filter synthesis plus EM calibration. The honest answer from this work
is that the *automation and diagnosis* were the AI contribution; the physics that
finally worked was textbook coupling-matrix design. Worth stating plainly — it is
a more useful result than overclaiming.
